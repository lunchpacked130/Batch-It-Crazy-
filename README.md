>[!WARNING]
>Some features will redraw the screen many times a second, depending on your CPU, this may result in blinking text.

<Details><summary>More info</summary>
This is usually no more than a couple of lines, and typically less than a quarter of a standard cmd/terminal window.
Any "full screen" color/brightness change is always at least 1 second apart, and if i haven't removed it before upload, there may be one that has 3 consequitve colorchanges over 3 seconds during an exit sequence.</details>

>[!TIP]
>You can force quit any batch file by closing the cmd/terminal window by clicking the X in the top right corner of the window.

<Details><summary>More ways to force quit or pause .bat files</summary>
• To force close the cmd/terminal window, press [Alt] + [F4]

• you can press the buttons [Ctrl] + [Alt] + [X] simultaneously to break the .bat peration.
This essentially pauses the operation as it asks you if you want to break the operation.
Pressing [N] will continue the operation and pressing [Y] will force exit the .bat file.
(If you run the batch file directly from windows, the cmd/terminal window will close when you force exit, though if you are running the .bat manually from command prompt by typing out the .bat file name, you will end up back at command prompt.)</details>
